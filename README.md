# One Line, One Laugh

> My therapist told me to stop blaming others, so I'm blaming her.

The turn lands in the second half: the therapist's advice to stop blaming others is immediately turned back on her — one clean, recursive twist in 64 characters.

## How to run

Run `node main.ts` (Node 22.18+). It writes the line to `/output/entry.txt` and prints it to stdout.

The entry is an original one-liner — not a known joke or recycled pun — written to meet the judge brief: one funny line, a real turn, every word earning its place, clear on first read.
